# Orbital Traffic 需求文档

## 1. Overview

一个基于真实全球航线分布的三维地球感官体验：数千架实例化飞机沿弧形航迹绕昼夜交界飞行，用户自由旋转和缩放地球，并以双指静止按住冻结空域、松手释放一次航班潮汐。

## 2. Visual Design

视觉基线直接保留 jeantimex 原作的世界地形纹理、半透明彩色航迹、8 类飞机、5,000 颗星、蓝色大气层、Phong 日照和昼夜终止线。产品 UI 只包含左上 2 行标题、当前可见航班数、底部双指隐藏动作提示和右上重播图标；不保留 dat.GUI、FPS 面板、作者页脚或设备外框。目标视口为 320×568、390×844 与 1440×900。

## 3. Game Mechanics

- 原版基线：加载全部 34,297 条航线数据，默认显示 3,500 架飞机与对应路径；相机半径从目标位置的 1.2 倍在延迟 1,000ms 后用 2,000ms 缓动进入昼夜交界视角。
- 产品移动端：装载 3,500 条航线；桌面装载 7,000 条航线；产品统一使用 2,048px 地球纹理，`?baseline=1` 始终使用原始 34,297 数据与原始 18MB 纹理。
- 双指同时落下后，若两点各自累计移动不超过 12px，持续 650ms 即进入 `frozen`；若超过阈值，只交给 OrbitControls 做缩放和旋转。
- `frozen` 时航班时间倍率在 220ms 内降到 0，地球日光降至 55%，航迹透明度提升到 0.82，持续到任一手指松开。
- 松开进入 `release`：航班倍率瞬时升至 2.4，在 1,800ms 内缓回原版 0.3；大气层做一次 700ms 亮度脉冲，随后回到 `idle`。
- 首次 5.2 秒幽灵双指演示必须走同一个冻结/释放状态机，而不是只移动图标。

## 4. Controls

- Pointer / Touch 单指拖动：OrbitControls 自由旋转地球。
- Touch 双指张合：OrbitControls 原生缩放；不触发隐藏动作。
- Touch 双指静止 650ms：冻结空域；松开释放航班潮汐。底部文字只说明这一隐藏动作。
- Mouse 滚轮：缩放；键盘空格：重新触发一次冻结—释放演示。

## 5. Win / Lose Conditions

本作没有失败。每次双指静止按住成功进入冻结、再松手完成 1,800ms 加速释放，即完成一轮体验闭环；HUD 的小型状态词从 `HOLD` 变为 `RELEASE`，随后回到当前航班数。

## 6. Sound Effects

- 首次真实输入后启用 Web Audio。
- 冻结阈值达到时以 84Hz 三角波在 160ms 内滑向 110Hz，最大音量 0.035。
- 冻结保持期间将三角波维持在音量 0.012；松手后 140ms 指数淡出。
- 释放时叠加 180Hz、270Hz、405Hz 三音，起始间隔 28ms，总时长 260ms。
