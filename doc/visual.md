# Orbital Traffic 视觉方向

## 方向

方向是“夜航管制室看见的活地球”，但不画控制室和设备。地球、航线、飞机和真实昼夜光照就是全部视觉奇观；界面只像印在画面边缘的航空图注。创新必须建立在原作的 Earth、Atmosphere、MergedFlightPaths、InstancedPlanes 与 OrbitControls 上，不用另一套粒子球近似。

## 构图

- 移动端地球直径占短边 130%–165%，允许裁出屏幕，制造巨大尺度；相机始终看向原点。
- 首帧先见星场与大气弧，随后在 3 秒内进入昼夜终止线视角。
- 左上标题位于安全区，右上仅 44×44 重播图标；底部提示高度 44px，不做面板堆叠。
- 冻结时不切镜头，直接在当前自由相机上提高同一批路径的亮度，保持空间连续性。

## 视觉系统

- 背景 `#02050A`，标题 `#EAF6FF`，次要文字 `rgba(210,232,245,.58)`。
- 强调色来自原作航迹本身：冰蓝 `#7AD7FF`、信号绿 `#7DFFC4`、暖黄 `#FFD66B`，不额外添加霓虹框。
- 字体使用 Arial / Helvetica；标题 24–38px、900 字重、负字距；图注 9–11px、大字距。
- 功能图标统一 1.5px SVG；幽灵手指使用 Google Material `touch_app` 原始路径，深蓝黑实体、冰蓝描边。
- Loading 为星场中的细弧扫描，不出现第三方 Logo 或旋转平台标记。

## 状态

- Loading：黑底、细地球弧与 `MAPPING AIRSPACE`，纹理加载完成且最短 900ms 后淡出。
- Idle：地球持续飞行，单指相机与双指缩放可用。
- Guided：两枚 Material 手指静止按住，真实航班速度降到 0，路径同步提亮；随后松开产生真实释放。
- Frozen：底部状态词 `AIRSPACE HELD`，路径更亮、地球更暗、飞机静止。
- Release：状态词 `TRAFFIC RELEASED`，大气层脉冲一次，飞机速度 2.4 倍后回落。
- Error：深黑全屏、冰蓝短句与轻触重载。

## 反模式

- 不保留 dat.GUI、FPS 计数器、GitHub 页脚或经纬度调试字样。
- 不用设备框、玻璃卡、雷达仪表盘或常规游戏 HUD 包住地球。
- 不占用单指做自定义动作；不取消 OrbitControls 的旋转和双指缩放。
- 不把双指静止动作误判为 pinch；任一手指移动超过 12px 就取消 hold。
- 不通过文字解释单指旋转；只提示隐藏的双指静止动作。
